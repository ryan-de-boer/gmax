# gmax
My gmax tools for exporting and importing obj files. Currently generated by Chat GPT Codex.

# Installation
* Install gmax12.exe from: https://archive.org/details/turbosquid-discreet-gmax-1.2
* Use the registration workaround registry .reg files from: https://neverwintervault.org/project/nwn1/other/tool/gmax-12-registration-workaround
* Use OpenGL driver, as the DirectX driver crashes when you set material to view in viewport when it contains a diffuse and opacity map - one of the disadvantages of using an old tool no longer supported bugs wont get fixed.

# Python files

# gmax_probe 
Parses gmax files displaying their content and optionally can export an obj file that can be imported into Blender etc. Only supports parametric boxes and editable meshes with no modifiers (just flatten them first).

$ python gmax_probe.py
Usage: gmax_probe.py path/to/file.gmax [--export-obj path/to/output.obj]

eg:
python gmax_probe.py C:\tmp\tree.gmax --export-obj C:\tmp\tree.obj

# to_gmax 
Imports an obj file into gmax. It relies on maxscript to do the import, I would have liked it to directly save to the gmax file but Codex thought it was a bit too risky since it doesn't know the file format well enough yet. I've made it support a large 50 meg obj so its fairly efficient.

$ python to_gmax.py -h

usage: to_gmax.py [-h] [--gmax-exe GMAX_EXE] [--timeout TIMEOUT] obj output

Convert a Wavefront OBJ into a native Gmax Editable Mesh scene. Gmax's binary
scene container is not written directly. This tool parses OBJ, generates a
temporary MAXScript that constructs editable meshes in Gmax, and asks the
installed Gmax executable to save the result as a .gmax file.

positional arguments:
  obj                  Input Wavefront OBJ file
  output               Output .gmax file

options:
  -h, --help           show this help message and exit
  --gmax-exe GMAX_EXE  Path to gmax.exe (default: C:\gmax\gmax.exe or
                       GMAX_EXE)
  --timeout TIMEOUT    Seconds to wait for Gmax to save (default: 180)


eg:
python to_gmax.py "c:\tmp\tree.obj" "c:\tmp\tree.gmax"
